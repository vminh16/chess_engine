# Design Specifications

This folder stores design documents that define or justify training objectives and pipeline choices.

- `loss_function_design.md`: loss geometry and objective design notes
- `ft1_full_retrain_pipeline_spec.md`: FT1 full-retrain specification
- `final_acchitecture/`: consolidated DGRN-X spec suite
  - `dgrn_x_program_suite_spec_vi_2026-05-05.md`: overview of the new DGRN-X spec suite
  - `dgrn_x_encode_refresh_spec_vi_2026-05-05.md`: input schema, history contract, and dataset refresh requirements
  - `dgrn_x_v0_value_teacher_spec_vi_2026-05-05.md`: fixed-topology value-only teacher spec
  - `dgrn_x_v1_policy_and_distillation_spec_vi_2026-05-05.md`: staged policy opening and distillation contract
  - `dgrn_x_rl_extension_spec_vi_2026-05-05.md`: RL extension rules after value/policy are stable
  - `dgrn_x_evaluation_protocol_spec_vi_2026-05-05.md`: validation, benchmark, and promotion protocol
