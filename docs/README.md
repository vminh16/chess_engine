# Documentation Index

The `docs/` tree is grouped by document purpose instead of historical creation order.

## Folders

- [`architecture`](architecture): diagrams and model specification assets
- [`design`](design): training/loss/pipeline specifications
- [`guides`](guides): practical guides for reading outputs and running workflows
- [`research`](research): root-cause analysis and experiment journal
- [`reports`](reports): project-level summaries, audits, and risk documents
