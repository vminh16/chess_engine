# Legacy Training Entry Points

This folder contains the original in-repo training pipeline and supporting FT1 helper code that predates the minimized Colab package in `train_v2_TF1/`.

Main files:
- `train.ipynb`: primary legacy notebook
- `train.py`: earlier script-based training entry point
- `ft1_colab_helpers.py`: FT1 helper copy used during notebook iteration

The detailed guide for reading FT1 `history.csv` metrics has been moved to [`docs/guides/ft1_history_metrics_guide.md`](../docs/guides/ft1_history_metrics_guide.md).
